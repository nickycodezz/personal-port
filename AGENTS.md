## Portfolio workflow

- Work in small, reviewable changes on a codex/ branch. Commit and push completed changes to GitHub so Nicole can review them. Do not merge into main or deploy without Nicole's explicit request.
- Preserve existing work and the earlier portfolio drafts. Use Draft 3 as a visual reference, migrating only the requested piece at a time.
- Use Nicole's real photographs and artwork, or appropriately licensed assets. Do not use AI-generated images for people or backgrounds.
- Aim for a recognizable Persona-inspired direction in sage green, pink, and cream. Keep the site accessible, responsive, and fast; respect reduced-motion preferences.
- Preserve working navigation unless a change is requested. Preview visual changes and run the checks appropriate to the change.
- Keep private originals, credentials, and local backups out of Git. Ask before adding personal photos to a public repository.
- Explain what changed and how to preview it in plain language. Nicole reviews the result before it is merged.
